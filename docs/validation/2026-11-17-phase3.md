## End-to-end tracker checks

`python tests/test_scan_board.py` uses the committed synthetic phantom.
For the two local NOVA-data cases, set `JAS_DATA_ROOT` to include the
`msd-liver` and `msd-hepaticvessel` folders shown in the
[dataset layout](../../datasets/README.md), then run:

```text
python -m pipeline.build --dataset msd-hepaticvessel --case hepaticvessel_424 --with-volume --out media/local/hepaticvessel_424
python -m pipeline.verify_bundle media/local/hepaticvessel_424
python tests/test_scan_board.py --case hepaticvessel_424
python -m pipeline.build --dataset msd-liver --case liver_39 --with-volume --out media/local/liver_39
python -m pipeline.verify_bundle media/local/liver_39
python tests/test_scan_board.py --case liver_39
```

return to surface mode and removal. The CT source pairs and generated scan
bundles stay in ignored local folders.

## Manual acceptance pending

Use the [Phase 3 checklist](../project/phase3-m3.md#manual-review-checklist)
for a physical webcam session and an imaging review. Record both hands,
viewports, cut tracking loss and reacquisition, hardware frame pacing
and real-case landmark/overlay agreement in millimeters. The real-case
smoke establishes that the pipeline and viewer run together. The imaging
review determines whether overlays meet the agreed tolerances.
